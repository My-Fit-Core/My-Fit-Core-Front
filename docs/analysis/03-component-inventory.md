## Instance와 원본 연결 확인 상태

- 최종 화면 XML에는 디자인 시스템 원본 이름과 같은 Instance 및 최종 페이지 원본 이름과 같은 Instance가 다수 보인다. `get_design_context`에서 `I...;...` 형태의 참조를 확인한 경우만 연결 근거로 사용한다.
- 옷장 검수 카드 `739:12677`은 `ClosetItemCard` Instance(`I739:12678;587:10660`)를 포함한다. 새 구현 기준 노드 `1039:19987`은 확인했지만 이 화면 Instance가 그 노드를 직접 참조하도록 바뀌었는지는 미확인이다. 버튼 조합 `677:12810`은 디자인 시스템 Button Instance를 포함하므로 해당 Button은 팀원 구현을 재사용한다.
- `Group 36`, `Group 28`, `Component 1`, `image 2/3/6`, `MFC`, `bottom navigation/nav bar`, `Time Picker Dialog / native UI`는 이름만으로 앱 내부 독립 컴포넌트가 필요한지 확정하지 않는다. Figma 원본 목록에는 포함하되 구현 목적을 별도 검토한다.
- 최종 디자인 원본이 온보딩에 사용되는 연결, 외부 라이브러리/분리된 Instance의 `mainComponent` ID는 현재 조회 도구에서 확인되지 않았다.
