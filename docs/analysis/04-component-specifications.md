# 사용자 담당 원본 컴포넌트 구현 명세

- 분석일: 2026-11-24
- 출처: Figma 최종 디자인 `2:6`의 전체 메타데이터와 아래 주요 노드의 `get_design_context`
- 범위: [인벤토리](03-component-inventory.md)의 사용자 담당 **32개 독립 구현 단위 후보 전체**. 실제 React 파일 32개를 뜻하지 않는다.
- 표기: **사실**은 Figma 조회값, **제안**은 React 설계, **미확정**은 API·모바일·원본 연결 등이다.

## 구현 공통 원칙

- 디자인 시스템 `2:4`의 Button, Navigation Bar, Icons, Option 계열은 팀원 제공 코드를 재사용한다. `ClosetItemCard`의 새 구현 기준 원본은 `1039:19987`로 확인됐으며 사용자 담당이다. `ClosetCard`와 동일하다고 간주하지 않는다. Figma MCP 생성 예시 코드는 복사하지 않는다.
- 375px Frame은 기준값이다. **제안:** 실제 화면에서는 `width: 100%`와 최대폭, 좌우 20~24px 여백, safe area, 스크롤을 검토한다. 이 반응형 규칙 자체가 Figma 확정 사양은 아니다.
- 모든 탭·버튼·카드 액션은 의미 있는 HTML 요소와 44px 안팎의 터치 영역을 사용하고 키보드 포커스·상태 이름을 제공한다. 모달은 포커스 이동/복귀·Escape·배경 스크롤 차단이 필요하다.
- 스타일 값은 [디자인 시스템](02-design-system.md)의 **확인된 값**과 각 원본의 직접 값을 구분한다. Tailwind v4와 팀원 토큰 API가 병합된 뒤 적용한다.
- Mock 데이터와 실제 API 상태를 분리한다. Figma는 서버 계약을 정의하지 않는다.
